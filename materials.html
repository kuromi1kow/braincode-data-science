Начало работы

Для первого урока достаточно браузера и Google Colab. Если хотите запускать код со своего компьютера, выберите Python с JupyterLab либо установите Miniconda и создайте учебное окружение.

  • Python · страница загрузкиВыберите поддерживаемую версию для своей системы. После установки проверьте в ячейке import sys и print(sys.version).
  • Python 3.12.0 · версия из вводного занятияАрхив страницы релиза из переписки. Для новой установки используйте основную страницу загрузки Python.
  • Miniconda · документацияМатериал из группы о conda. Изолированное окружение помогает закрепить версии библиотек для одного проекта.
  • Anaconda · инструкции для вашей системыВыберите Miniconda и свою ОС. На macOS сверяйте архитектуру установщика с процессором компьютера.
  • JupyterLab · установка и запускПосле установки запустите jupyter lab из терминала в папке учебных файлов. Откройте .ipynb и выполните первую ячейку.
  • Python Tutorial · официальное руководствоОткройте раздел текущей темы. Скопируйте короткий пример и поменяйте одно входное значение.

Задачи и видео

Сначала решите пример самостоятельно. Видео и тренажёр помогут проверить ход рассуждения и разобрать момент, на котором возник вопрос.

  • Домашняя работа по NumPy · 100 упражненийОткройте условия и ученический блокнот. Выполните задания № 1–100 и сдайте свою копию с результатами.
  • Питонтьютор · задачи на русскомВыберите ввод и вывод, условия, циклы, функции или коллекции. Сохраните короткий вход, на котором решение сначала ошиблось.
  • Объединение и пересечение · задачиНарисуйте две группы клиентов на бумаге, затем соберите множества в Python и проверьте размер пересечения.
  • Диаграммы Венна · видеоОстановитесь на рисунке двух множеств. Какие области соответствуют A | B и A & B? Придумайте свой пример с общим клиентом.
  • Умножение матриц · видеоПосле урока NumPy сравните поэлементное A * B и матричное A @ B. Для второй операции одна строка умножается на один столбец с последующим сложением.

Математика для самостоятельного чтения

Эти книги преподаватель рекомендовал для дополнительной практики. Чтобы начать NumPy, достаточно считать элементы и различать строки и столбцы. К доказательствам и производным можно возвращаться по мере необходимости.

  • Гилберт Стрэнг · CalculusОткрытый учебник MIT. Начните с примера изменения величины со временем: по двум соседним измерениям можно оценить среднюю скорость изменения.
  • Шелдон Экслер · Linear Algebra Done RightОткрытое четвёртое издание, PDF на английском. Попробуйте записать пару координат и объяснить сложение векторов на плоскости.
  • Гилберт Стрэнг · Introduction to Linear AlgebraАвторская страница шестого издания с оглавлением и главами для знакомства. Посмотрите на матрицу через её столбцы.
  • С. А. Логвенков, В. С. Самовол · Линейная алгебраРусскоязычное пособие с задачами, PDF на сайте ВШЭ. Вычислите произведение небольших матриц на бумаге и проверьте ответ в NumPy.
  • Джейк Вандер Плас · Python для сложных задачСтраница русского издания у издателя. Английские главы о массивах и масках открыты на сайте автора и собраны в книжной полке курса.
