С чего начать

Функция превращает повторяемый расчёт в именованную операцию. Явные параметры помогают проверять код и использовать его снова.

Как договориться о результате функции

Сначала напишите на листе один вызов и тот результат, который вы ожидаете. Например, средний чек для [200, 300] равен 250. Функция должна получить список через параметр и вернуть число, чтобы следующая строка могла его округлить или сравнить с порогом.

Один и тот же расчёт можно применять к разным кассам. У каждого вызова свои параметры и локальные имена. Для пустого списка среднего нет: заранее договоритесь, вернёт ли функция None или сообщит об ошибке. Затем проверьте этот случай отдельно.

Перевод для курса

Зачем давать вычислению имя

Функции — это части программы, которые можно использовать повторно. Они позволяют дать имя блоку инструкций и выполнять этот блок по имени в любом месте программы столько раз, сколько понадобится. Такое действие называют вызовом функции. Нам уже встречались встроенные функции, например len и range.

Оригинал и перевод этого отрывка · Swaroop Chitlur · A Byte of Python · CC BY-SA 4.0

Прочитать английский оригинал

Functions are reusable pieces of programs. They allow you to give a name to a block of statements, allowing you to run that block using the specified name anywhere in your program and any number of times. This is known as calling the function. We have already used many built-in functions such as len and range.

Как это проверить

В расчёте выручки есть два действия: описать правило и применить его к конкретным числам. Если определить def revenue(price, qty), значение ещё не вычислено. При вызове revenue(60, 3) параметры получат аргументы, а возвращаемый результат можно присвоить переменной или проверить через assert.

Почему напечатанная функцией сумма иногда превращается в None?

В двух отчётах нужна одна операция: из цены получить сумму после скидки. Опишите функцию discounted(price, rate), где price задана в тенге, а rate задаёт долю скидки от 0 до 1. Для аргументов 2000 и 0.15 размер скидки равен 300, результат равен 1700. Зафиксируйте этот пример до написания тела функции. Тогда известен смысл каждого аргумента и единицы результата.

Если последняя строка функции вызывает только print, число увидит человек, но выражение discounted(2000, 0.15) вернёт None. Когда отчёт попытается прибавить доставку 200, Python выдаст ошибку сложения. Строка return price * (1 - rate) передаёт число вызывающему коду. Теперь один отчёт может показать 1700, а другой посчитать 1900 с доставкой.

Пусть в соседней ячейке ноутбука переменная price равна 500. Во время вызова параметр price внутри функции получает переданное значение 2000. Если случайно читать ставку из внешней переменной, повторный запуск после другого отчёта способен изменить результат. Передавайте изменяемые условия расчёта явно и проверяйте нулевую скидку как простейший случай.

О чём договориться до первой строки def?

Организатор поездки просит написать функцию для подсчёта автобусов. В один автобус помещаются двадцать человек. Фраза «разделить число пассажиров на вместимость» звучит убедительно, пока не возникает группа из двадцати одного человека. Ответ 1,05 автобуса описывает отношение величин. Организатору требуется целое число машин, достаточное для всех пассажиров. Этот нюанс нужно включить в договор о результате.

Удобно записать несколько вызовов ещё до кода. Для пустой группы результат равен нулю. Для одного человека нужен один автобус, для двадцати тоже один, а для двадцати одного уже два. В качестве допустимого входа берём целое неотрицательное число пассажиров и положительную целую вместимость. Если кто-то передал нулевую вместимость, задача перестаёт иметь смысл. Такой ввод стоит отклонить до деления, например сообщив об ошибке значения.

Теперь формулу легко вывести. Целочисленное деление показывает количество полностью заполненных автобусов. Остаток сообщает, есть ли люди, которым понадобится ещё одна машина. Мы можем объяснить каждую проверку человеку, организующему поездку. Эти же примеры пригодятся позже, когда понадобится заменить фиксированную вместимость параметром и снова убедиться в правильности вычислений.

Кто решает, куда попадёт ответ функции?

Лаборант переводит показания датчика из десятых долей градуса в обычные градусы. Так, запись 186 означает 18,6 градуса. Один коллега выводит температуру на экран, другой сохраняет её в таблицу, третий сравнивает её с верхним порогом. Им пригодится одна функция, если после перевода она отдаст вызывающему коду обычное число. Куда это число направить дальше, каждый решит в своей строке.

Представьте вызов degrees(186). Внутри функции данные делятся на десять, затем return передаёт результат обратно в точку вызова. Можно связать его с именем t и вычислить t > 20. Получится False. Команда print понадобится только тому, кто хочет увидеть число на экране. Если завершить функцию одной печатью, вывод 18.6 всё равно появится, но переменная t получит служебное значение None. Последующая попытка сравнить его с числом приведёт к ошибке типа.

Для проверки удобно записать отдельно две строки: сначала присвоить результат, затем вывести его и его тип. Это выявляет функции, которые кажутся рабочими при показе с экрана, но ломаются при совместном использовании в отчёте. К строковому оформлению и единицам измерения в подписи имеет смысл переходить в самом конце.

Почему повторный вызов начинает расчёт с чистого листа?

Туристическое бюро печатает номер ряда по месту пассажира. В каждом ряду четыре кресла, места нумеруются с единицы. Для мест с первого по четвёртое нужен первый ряд; пятое место открывает второй. Сначала мысленно вычтем единицу из номера места. Тогда первые четыре позиции имеют значения 0, 1, 2 и 3, и все четыре при целочисленном делении на четыре дают ноль. Прибавление единицы переводит результат обратно в обычный номер ряда.

В функции row_number(seat) можно сохранить seat - 1 под локальным именем index. Когда передаём место 5, index равен четырём, а функция возвращает ряд 2. При следующем вызове для места 1 параметр seat получает новое значение, и index вычисляется заново. Локальные имена каждого вызова существуют внутри этого расчёта. Даже если в блокноте есть внешнее имя index со значением 99, присваивание внутри такой функции его не изменит.

Типичная трудность возникает при попытке вывести локальный index уже после вызова. Если снаружи такого имени нет, Python сообщит NameError; если оно есть, на экран попадёт внешнее значение. Когда для отчёта нужен результат, берите его из return и сохраняйте в переменной там, где собирается отчёт.

Как повторить расчёт для двух заказов?

Стоимость строки заказа равна цене за единицу, умноженной на количество. Дадим этому правилу имя, чтобы его можно было вызвать с разными числами.

Python
def cost(price, count):
    return price * count

print(cost(250, 3))
print(cost(100, 2))
Показать вывод и объяснение
750
200

Строка def объявляет функцию, а price и count служат именами для входных значений. При первом вызове они получают 250 и 3. Команда return отдаёт произведение вызывающему коду, поэтому одно и то же тело обслуживает оба заказа.

Где живёт промежуточная сумма?

При расчёте суммы с доставкой удобно сохранить промежуточное число. Даже если снаружи уже существует имя total, функция может иметь своё локальное значение.

Python
total = 50
def with_delivery(goods):
    total = goods + 200
    return total

print(with_delivery(600))
print(total)
Показать вывод и объяснение
800
50

Присваивание внутри функции создаёт локальное имя total. Вызов возвращает 800, а после него команда print(total) обращается к внешнему значению 50. Чтобы использовать результат позже, его можно сохранить при вызове под отдельным именем.

Что вернуть, если наблюдений пока нет?

Для отчёта требуется средняя сумма продажи. До первого заказа среднее вычислить нельзя, поэтому договоримся возвращать специальное значение None для пустого набора.

Python
def average(total, count):
    if count == 0:
        return None
    return total / count

print(average(900, 3))
print(average(0, 0))
Показать вывод и объяснение
300.0
None

Условие проверяется до деления. При нулевом count первый return сразу завершает функцию, так что до опасной операции выполнение не дойдёт. Результат None помогает отличить отсутствие наблюдений от среднего ноль, которое бывает при реальных бесплатных покупках.

Лаборатория · Сколько продлится выпуск студенческого подкаста?

Редактор соединяет две записи и вставляет заставку между ними. Подготовьте функции для перевода длительностей в общую единицу, вычисления итога и печати в формате минут и секунд.

Исходные данные

Первый фрагмент длится 1 минуту 59 секунд, второй — 1 минуту 5 секунд, заставка — 12 секунд. В исходных парах секундная часть лежит в диапазоне 0–59.

Запустить лабораторию в Colab

Шаг 1. Как сравнивать и складывать длительности?

Python
def to_seconds(minutes, seconds):
    return minutes * 60 + seconds

first = to_seconds(1, 59)
second = to_seconds(1, 5)
print(first, second)
Проверить результат
119 65

У каждой исходной записи два числа в разных единицах. Функция переводит минуты в секунды и возвращает одно целое число. После вызовов first и second содержат сопоставимые величины.

Шаг 2. Как добавить заставку один раз на стыке фрагментов?

Python
def episode_length(left, right, intro):
    return left + intro + right

length = episode_length(first, second, 12)
print(length)
Проверить результат
196

Параметры left, right и intro обозначают секунды и получают значения из вызова. Внутри функции заставка участвует в сложении ровно один раз. Результат можно сохранить в length и передать дальше, поэтому внутри функции ничего печатать не требуется.

Шаг 3. Как вернуть слушателю привычную запись времени?

Python
def time_label(total):
    minutes = total // 60
    seconds = total % 60
    return f"{minutes}:{seconds:02d}"

print(time_label(length))
print(time_label(65))
Проверить результат
3:16
1:05

Целочисленное деление даёт число полных минут, а остаток — секунды после них. В форматированной строке выражение seconds:02d отводит под целое число две позиции и при необходимости ставит слева ноль. Отдельная проверка числа 65 помогает заметить пропущенный ведущий ноль.

Программа выполняется. Где ошибка в выводе?

Python
as_digits = 159 + 105 + 12
print(as_digits // 100, as_digits % 100)
Разобрать ошибку
2 76

Записи 1:59 и 1:05 были склеены в десятичные числа. Цифры переносятся в следующий разряд после ста, а минуты должны увеличиваться после шестидесяти секунд. Поэтому 2 минуты 76 секунд — некорректная запись; используйте to_seconds перед сложением и time_label после него.

Вызов функции сохраняет результат в переменную, чтобы использовать дальше

Python
def average(values):
    if not values:
        return None
    return sum(values) / len(values)

result = average([2, 4, 6])
print(result)
assert result == 4
assert average([]) is None

Отсутствующий return означает возврат None. Не надо изменять глобальную total ради вычисления среднего. Изменяемый аргумент по умолчанию, например values=[], создаётся один раз и может сохранять состояние между вызовами.
