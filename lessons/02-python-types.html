С чего начать

Программа хранит значения и преобразует их. Научимся считать стоимость заказа и понимать, почему одинаковые символы могут означать разные данные.

Как Python читает строку программы

Когда вы пишете price = 1200, Python вычисляет выражение справа и связывает имя price с целым числом. Следующая строка может использовать это имя. Запись print(price) показывает значение, а print("price") показывает пять букв. Кавычки меняют смысл программы.

В Colab результат предыдущего запуска остаётся на экране даже после редактирования строки. Поменяйте 1200 на 900 и запустите вычисления снова сверху вниз. Если два одногруппника видят разные результаты, сначала сравните входные значения и порядок запуска.

int
Целое число, например количество заказов.
float
Число с плавающей точкой, например 0.15 для доли скидки.
str
Текст. Запись '12' состоит из двух символов; для арифметики можно получить целое число через int('12').

Почему одинаковая запись «3» ведёт себя по-разному при расчёте заказа?

Кассир вводит количество билетов в текстовое поле. Для человека запись 3 сразу означает число, а программа получает строку. Проверьте промежуточное значение вызовом type. При умножении строки '3' на 2 Python повторяет символ и получает '33'. Показ такого результата покупателю выглядел бы как вычисление, хотя смысл операции совсем другой.

Пусть один билет стоит 850 тенге, а за весь заказ берут сбор 100 тенге. Преобразуйте количество через int, затем отдельно вычислите стоимость билетов и прибавьте сбор. Для трёх билетов промежуточный итог равен 2550, к оплате 2650. Если сначала прибавить сбор к цене и умножить результат на три, получится 2850. Разница объясняется тем, сколько раз применили сбор. Скобки позволяют явно выразить выбранное правило.

В таблице доставки похожие столбцы могут представлять массу как число и номер посылки как текст. Номер '003' важно сохранить строкой, иначе потеряются начальные нули. Перед преобразованием ответьте на простой вопрос: имеет ли сложение двух таких значений смысл для задачи?

Проверьте рассуждение

Покупатель ввёл '04'. Сколько надо списать за четыре билета по этому правилу и зачем здесь int?

Сверить ответ

4 × 850 + 100 = 3500 тенге. Количество участвует в арифметике, поэтому int('04') уместен. В идентификаторе заказа начальный ноль мог бы быть значимым.

Как дать числу понятное имя?

На складе осталось семь коробок. Сохраните это число под именем boxes, чтобы использовать его в следующей строке без повторного ввода.

Python
boxes = 7
print(boxes * 4)
Показать вывод и объяснение
28

Знак равенства связывает имя слева со значением справа. Во второй строке Python подставляет вместо boxes число 7. Если в каждой коробке четыре кружки, произведение даёт общее количество кружек.

Почему «12» и 12 ведут себя по-разному?

При чтении формы количество часто приходит как текст. Сначала посмотрите, как Python соединяет текст, затем переведите тот же ввод в целое число.

Python
entered = "12"
print(entered + "3")
print(int(entered) + 3)
Показать вывод и объяснение
123
15

Кавычки делают 12 строкой, и плюс между двумя строками склеивает их символы. Вызов int(entered) возвращает целое число 12. Теперь по обе стороны плюса числа, поэтому последняя строка печатает сумму 15.

Сколько получится полных упаковок?

В отделе выдачи нужно разложить 29 маркеров по коробкам по шесть. Одного деления мало: нам нужны и количество заполненных коробок, и число оставшихся маркеров.

Python
markers = 29
capacity = 6
full = markers // capacity
left = markers % capacity
print(full, left)
Показать вывод и объяснение
4 5

Оператор // для этих положительных чисел даёт целую часть частного, а % даёт остаток. Имена full и left хранят разные ответы на один вопрос о делении. Проверить вывод можно обратным действием: четыре коробки по шесть плюс пять маркеров дают исходные 29.

Практика и домашнее задание

Пример из блокнота

Цена 2 500 ₸, количество 3, скидка 10%

Сумма до скидки: 2 500 × 3 = 7 500 ₸

К оплате: 7 500 × 0.9 = 6 750 ₸

Python
price = 2500
quantity = 3
discount = 0.10
subtotal = price * quantity
total = subtotal * (1 - discount)
print(type(price).__name__)
print(f"К оплате: {total:.2f} ₸")
assert total == 6750

Вычисление выполняется справа от знака присваивания, затем имя связывается с результатом. Формат .2f влияет на вывод, а не точность хранения. Для денежных расчётов в продукте обычно применяют целые минимальные единицы или Decimal.

  2. Посчитать итог: цена 1 200, количество 5, скидка 15%.

Самопроверка

Какой тип возвращает input()?

str.

Чем / отличается от //?

/ выполняет обычное деление, // округляет результат вниз до целого частного.

Что вернёт "5" * 3?

Строку "555".

Где легко ошибиться

  • "3" + "4" даёт "34": сначала преобразовать строки
  • 0.1 + 0.2 хранится приближённо: сравнивать с допуском
  • Знак = присваивает значение, == сравнивает значения
