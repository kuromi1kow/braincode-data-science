Как Python читает строку программы

Когда вы пишете price = 1200, Python вычисляет выражение справа и связывает имя price с целым числом. Следующая строка может использовать это имя. Запись print(price) показывает значение, а print("price") показывает пять букв. Кавычки меняют смысл программы.

В Colab результат предыдущего запуска остаётся на экране даже после редактирования строки. Поменяйте 1200 на 900 и запустите вычисления снова сверху вниз. Если два одногруппника видят разные результаты, сначала сравните входные значения и порядок запуска.

int
Целое число, например количество заказов.
float
Число с плавающей точкой, например 0.15 для доли скидки.
str
Текст. Запись '12' состоит из двух символов; для арифметики можно получить целое число через int('12').

Почему пробелы могут менять смысл

Пробелы в Python имеют значение. Если точнее, важны пробельные символы в начале строки. Это называется отступом. Начальные пробелы или табуляции определяют уровень отступа логической строки, а от уровня зависит, какие инструкции окажутся в одной группе. Инструкции, составляющие такую группу, должны иметь одинаковый отступ. Такая группа называется блоком. Примеры с блоками встретятся в следующих главах.

Оригинал и перевод этого отрывка · Swaroop Chitlur · A Byte of Python · CC BY-SA 4.0

Прочитать английский оригинал

Whitespace is important in Python. Actually, whitespace at the beginning of the line is important. This is called indentation. Leading whitespace (spaces and tabs) at the beginning of the logical line is used to determine the indentation level of the logical line, which in turn is used to determine the grouping of statements.

This means that statements which go together must have the same indentation. Each such set of statements is called a block. We will see examples of how blocks are important in later chapters.

Почему одинаковая запись «3» ведёт себя по-разному при расчёте заказа?

Кассир вводит количество билетов в текстовое поле. Для человека запись 3 сразу означает число, а программа получает строку. Проверьте промежуточное значение вызовом type. При умножении строки '3' на 2 Python повторяет символ и получает '33'. Показ такого результата покупателю выглядел бы как вычисление, хотя смысл операции совсем другой.

Пусть один билет стоит 850 тенге, а за весь заказ берут сбор 100 тенге. Преобразуйте количество через int, затем отдельно вычислите стоимость билетов и прибавьте сбор. Для трёх билетов промежуточный итог равен 2550, к оплате 2650. Если сначала прибавить сбор к цене и умножить результат на три, получится 2850. Разница объясняется тем, сколько раз применили сбор. Скобки позволяют явно выразить выбранное правило.

В таблице доставки похожие столбцы могут представлять массу как число и номер посылки как текст. Номер '003' важно сохранить строкой, иначе потеряются начальные нули. Перед преобразованием ответьте на простой вопрос: имеет ли сложение двух таких значений смысл для задачи?

Что означает число, пока оно ещё лежит в текстовом поле?

Метеокружок просит записать температуру в комнате и заводской номер термометра. На экране появляются две последовательности символов: '21.5' и '0042'. Вызов input возвращает строку даже тогда, когда вы нажимали только цифровые клавиши. Сначала решите, какая операция будет происходить дальше. Температуру собираются сравнить с показанием другого прибора и усреднить. Номер нужен, чтобы отыскать запись об устройстве. Внешний вид двух полей мало помогает выбрать подходящий тип.

Для температуры подходит float('21.5'). Если второе показание равно 22.5, среднее равно 22.0 градуса. Вызов int('21.5') выдаст ValueError, поскольку строка с десятичной точкой не записывает целое число в том формате, который ожидает int. Выражение int(float('21.5')) уже даст 21, однако после него пропадёт половина градуса. Если же превратить заводской номер в int, значение станет 42 и запись потеряет начальные нули.

Попросите одногруппника ввести '21,5'. Функция float ожидает десятичную точку и не принимает такую строку напрямую. Можно заранее договориться о формате ввода и дать пример возле поля. Если приложение поддерживает запятую как разделитель дробной части, это правило стоит явно описать. В текстовом комментарии сохраните единицы измерения, потому что число 21.5 само по себе их не хранит.

Как узнать, какое значение переменная помнит на конкретной строке?

Представьте электронное табло в магазине бумаги. Сначала дежурный положил на полку 18 пачек. Затем он пересчитал остаток для промежуточного отчёта и переложил пять пачек на другой этаж. Нужно напечатать как исходное количество, так и новый остаток. Заведите имена stock для доступных пачек и snapshot для числа, записанного при пересчёте. Посмотрите, в какой момент значение появляется у каждого имени.

В таблице одна строка программы соответствует одному выполненному присваиванию. В выражении stock = stock - 5 Python сначала читает текущее значение справа, считает 18 минус 5 и связывает имя слева с числом 13. Прежнее значение, на которое указывало имя snapshot, при этом продолжает быть доступно через snapshot. Для целых чисел это позволяет сохранить результат предыдущего шага простым присваиванием.

Теперь мысленно перенесите строку snapshot = stock ниже вычитания. Программа выполнится без сообщения об ошибке, но оба имени к моменту печати будут указывать на 13. Перепутанный порядок исполнения выявляет проверка вопросом «что записано к этому моменту?». Как прочитать TypeError и найти причину, не угадывая?

Программа рассчитывает объём краски в двух банках. В первой 2 литра, содержимое второй пользователь вводит с клавиатуры как 1.5. Место сбоя выглядит безобидно: total = first + second. В последней строке сообщения Python видны слова TypeError и упоминание int и str. Посмотрите на строку ошибки, затем проследите, откуда пришёл каждый операнд. В правой части выражения одно значение хранит число 2, другое всё ещё хранит три текстовых символа.

Поставьте над вычислением диагностическую строку print(repr(second), type(second)). Функция repr показывает строку с кавычками, что помогает заметить текстовое представление, даже когда обычный print выводит его почти так же, как число. Если вход принимает дробные литры, переведите second через float и повторите расчёт. Для нашего примера получится 3.5 литра. Заранее записанный ожидаемый ответ сразу покажет, исправили ли вы смысл вычисления.

Встречается соблазн привести оба операнда к строкам, чтобы прекратилось сообщение об ошибке. Программа тогда склеит '2' и '1.5' в '21.5'. Показания на банках не изменились, поэтому такой итог явно неверен. Если после правильного преобразования возникает ValueError на вводе 'полбанки', это уже другая проблема. Строка не записывает число в согласованном формате, и пользователю нужен пример допустимой записи.

Как дать числу понятное имя?

На складе осталось семь коробок. Сохраните это число под именем boxes, чтобы использовать его в следующей строке без повторного ввода.

Python
boxes = 7
print(boxes * 4)
Показать вывод и объяснение
28

Знак равенства связывает имя слева со значением справа. Во второй строке Python подставляет вместо boxes число 7. Если в каждой коробке четыре кружки, произведение даёт общее количество кружек.

Почему «12» и 12 ведут себя по-разному?

При чтении формы количество часто приходит как текст. Сначала посмотрите, как Python соединяет текст, затем переведите тот же ввод в целое число.

Python
entered = "12"
print(entered + "3")
print(int(entered) + 3)
Показать вывод и объяснение
123
15

Кавычки делают 12 строкой, и плюс между двумя строками склеивает их символы. Вызов int(entered) возвращает целое число 12. Теперь по обе стороны плюса числа, поэтому последняя строка печатает сумму 15.

Сколько получится полных упаковок?

В отделе выдачи нужно разложить 29 маркеров по коробкам по шесть. Одного деления мало: нам нужны и количество заполненных коробок, и число оставшихся маркеров.

Python
markers = 29
capacity = 6
full = markers // capacity
left = markers % capacity
print(full, left)
Показать вывод и объяснение
4 5

Оператор // для этих положительных чисел даёт целую часть частного, а % даёт остаток. Имена full и left хранят разные ответы на один вопрос о делении. Проверить вывод можно обратным действием: четыре коробки по шесть плюс пять маркеров дают исходные 29.
