С чего начать

Цикл повторяет действие для набора объектов. Вместо ручного расчёта каждой продажи посчитаем дневную выручку.

Что меняется за одну итерацию

При обходе списка for берёт очередной элемент и связывает его с именем после for. Внутри цикла удобно мысленно держать две колонки: текущий элемент и то, что уже насчитано. Запишите значения после первого шага и попробуйте продолжить трассировку без компьютера.

Для while сформулируйте условие продолжения и действие, которое приближает конец. Например, при обратном отсчёте n > 0 должно однажды стать ложным: после вывода числа уменьшаем n на один. При начальном n = 0 тело вообще не выполнится.

Итерация
Одно выполнение тела цикла.
Накопитель
Переменная для промежуточного итога. Начальное значение задаётся перед циклом.
range
Последовательность целых чисел для обхода. Правая граница в неё не входит.

Перевод для курса

Что именно возвращает range

В этом примере мы печатаем последовательность чисел. Она создаётся встроенной функцией range. Мы передаём ей два числа и получаем последовательность от первого числа до второго. Например, range(1, 5) даёт значения 1, 2, 3, 4. По умолчанию шаг равен единице. Если передать третье число, оно станет шагом. Так, range(1, 5, 2) даёт 1 и 3. Вторая граница задаёт остановку и сама в последовательность не входит.

Оригинал и перевод этого отрывка · Swaroop Chitlur · A Byte of Python · CC BY-SA 4.0

Прочитать английский оригинал

In this program, we are printing a sequence of numbers. We generate this sequence of numbers using the built-in range function.

What we do here is supply it two numbers and range returns a sequence of numbers starting from the first number and up to the second number. For example, range(1,5) gives the sequence [1, 2, 3, 4]. By default, range takes a step count of 1. If we supply a third number to range, then that becomes the step count. For example, range(1,5,2) gives [1,3]. Remember that the range extends up to the second number i.e. it does not include the second number.

Как это проверить

Если нужно подписать пять рабочих дней числами с 1 по 5, укажите range(1, 6). Если нужно пройти по пяти позициям списка, подойдёт range(5), потому что первая позиция нулевая. В обеих задачах пять шагов, но подписи у них разные.

Как считать среднее время доставки, если часть заказов ещё в пути?

В журнале стоят четыре значения в минутах: 12, None, 18 и 0. None означает, что заказ ещё не выдан. Ноль означает выдачу сразу при оформлении. Оба значения требуют внимания, но только ноль представляет измеренное время. Сначала сформулируйте, какие заказы должны попасть в знаменатель.

До цикла установите сумму минут и число завершённых заказов в ноль. Для 12 они станут равны 12 и 1. При None пропустите обновление. После 18 накоплено 30 минут по двум заказам. Последний ноль оставляет сумму равной 30 и увеличивает счётчик до трёх. Среднее по завершённым заказам равно десяти минутам. Теперь можно проверить каждое изменение, даже если программа напечатала только итог.

Запись if minutes отбрасывает и None, и 0. Тогда программа выдаст 15 минут, хотя все сложения сработали правильно. Проверяйте условие включения явно, например minutes is not None. Если все четыре заказа ещё в пути, сообщите, что завершённых наблюдений пока нет. Деление имеет смысл только при положительном счётчике.

Сколько раз в аудитории становилось шумно?

Шумомер снимает одно показание в минуту. Для этой задачи назовём минуту громкой, если показание не ниже 70. Преподаватель хочет знать, сколько раз начинался громкий период. Если шум держался три минуты подряд, это один период. Первый соблазн — прибавлять единицу при каждом показании от 70. Такой расчёт отвечает на другой вопрос и завышает число отдельных событий.

Возьмём пять показаний по порядку: 68, 72, 75, 65, 70. Перед первым измерением договоримся считать, что в аудитории было тихо. Перед очередной итерацией нам нужны два значения: сколько периодов уже началось и была ли предыдущая минута громкой. На текущем шаге определим громкость, затем прибавим единицу только при переходе из тишины в шум. В самом конце шага запомним состояние текущей минуты для сравнения со следующей.

Посмотрите на третью строку таблицы. Значение 75 выше порога, но счётчик остался прежним: обе соседние минуты громкие. Если перепутать порядок действий и записать текущее состояние раньше сравнения, программа на каждом шаге будет сравнивать минуту с ней самой. Именно для поиска таких ошибок делают трассировку — выписывают состояние программы после каждого шага.

Чем руководствоваться при выборе for и while?

Пекарня получила заказ на 17 булочек. На противне помещаются шесть. Есть две разные работы: разложить известные начинки по готовым коробкам и последовательно занять столько противней, сколько потребуется. В первом случае у нас уже есть перечень коробок. При обходе через for Python сам переходит к следующей коробке и остановится, когда весь перечень закончится. Повторяющиеся начинки при таком обходе сохраняются.

Для загрузки противней удобно следить за остатком. Начнём с 17. Пока остаток положительный, кладём на противень меньшую из двух величин — вместимость и число булочек, которые ещё лежат на столе. После первого противня осталось 11, после второго пять, после третьего ноль. Здесь буквально читается условие while remaining > 0. Внутри каждого шага остаток убывает хотя бы на единицу, поэтому у цикла есть понятный момент завершения.

Проверьте правило на заказе из двенадцати булочек. После двух шагов остаток уже нулевой. Если записать remaining >= 0, цикл попытается обработать пустой противень. Для пустого заказа тело корректного while не выполнится ни разу. Такая проверка особенно хорошо показывает, какую роль играет знак сравнения.

Когда накопленный результат уже окончателен?

Сканер проверяет измерения напряжения в том порядке, в котором они записаны. Прибор иногда передаёт пустой замер. Нужно назвать первое известное напряжение выше 240 вольт и минуту, когда оно встретилось. После этого продолжение поиска уже не изменит ответ. Заранее договоримся нумеровать минуты с единицы и сохранять их исходные номера даже для пустых замеров.

Предположим, что записи выглядят так: 229, пусто, 238, 243, 250. На первой минуте идём дальше. На второй пропускаем саму проверку напряжения, потому что сравнивать пустоту с числом нельзя. Команда continue в Python сразу начинает следующую итерацию. На третьей минуте напряжение по-прежнему допустимое. На четвёртой сохраняем результат и выполняем break — выходим из ближайшего цикла. Пятое значение больше предыдущего, однако задача про первое превышение уже решена.

Полезно заранее обозначить отсутствие результата, например значением None. Тогда после обхода можно отдельно сообщить, что превышений не найдено. Проверьте, как вы записываете номер минуты: если собственный счётчик увеличивается после continue, пропущенный замер исчезнет из нумерации. В Python вызов enumerate(замеры, start=1) выдаёт номер вместе с каждым исходным элементом, включая пустые записи.

Что меняется при каждом проходе?

Три замера температуры записаны по порядку в квадратных скобках. Цикл позволяет выполнить одно действие с каждым замером, даже если значения повторяются.

Python
for temperature in [18, 20, 18]:
    print(temperature)
Показать вывод и объяснение
18
20
18

На первом проходе имя temperature получает 18, на следующем — 20, на последнем — снова 18. Команда с отступом выполняется каждый раз для текущего значения. Последнее число тоже печатается, потому что цикл обходит все три позиции.

Как накопить дневную выручку?

За три заказа заплатили 300, 500 и 200 тенге. Вместо отдельных имён для промежуточных сумм будем обновлять один накопитель и видеть его после каждой оплаты.

Python
total = 0
for payment in [300, 500, 200]:
    total = total + payment
    print(total)
Показать вывод и объяснение
300
800
1000

Начальное значение ноль задаётся один раз перед циклом. Правая часть присваивания использует предыдущую сумму, прибавляет очередную оплату и сохраняет результат обратно в total. Если переместить обнуление внутрь цикла, на экране будут только суммы отдельных оплат.

Когда закончится обратный отсчёт?

Для короткого таймера заранее известно условие продолжения: пока осталось хотя бы одно деление, нужно вывести число. Здесь удобно явно хранить остаток и уменьшать его.

Python
left = 3
while left > 0:
    print(left)
    left = left - 1
print("Старт!")
Показать вывод и объяснение
3
2
1
Старт!

Перед каждой итерацией while проверяет выражение left > 0. После печати единицы счётчик уменьшается до нуля, и следующая проверка завершает цикл. Финальный print стоит без отступа и выполняется один раз даже при начальном left = 0.

Лаборатория · В какой день выполнена учебная цель?

Наставник дал студенту цель — посвятить упражнениям не менее 45 минут за несколько дней. Постройте накопительный итог и определите первый день, когда условие выполнено. Пустой по занятиям день всё равно присутствует в календаре.

Исходные данные

Минуты практики по дням: 12, 0, 18, 9, 6, 20. Нумерация дней начинается с единицы. Длительности неотрицательные, цель положительная.

Запустить лабораторию в Colab

Шаг 1. Сколько минут в журнале и сколько из них пришлось на каждый день?

Python
minutes = [12, 0, 18, 9, 6, 20]
total = 0
day = 0
for duration in minutes:
    day += 1
    total += duration
    print(day, duration, total)
Проверить результат
1 12 12
2 0 12
3 18 30
4 9 39
5 6 45
6 20 65

Три числа в строке означают номер дня, продолжительность занятия и сумму с начала наблюдения. При значении 0 номер дня растёт, хотя сумма остаётся прежней. Поэтому вторую строку журнала важно сохранить в обходе.

Шаг 2. Как остановиться на первом выполнении цели?

Python
goal = 45
day = 0
total = 0
for duration in minutes:
    day += 1
    total += duration
    if total >= goal:
        break
print(day, total)
Проверить результат
5 45

Перед новым обходом оба накопителя снова начинаются с нуля. Сравнение выполняется после добавления текущего дня, поэтому в проверку уже входят его шесть минут. При первом подходящем результате break прекращает цикл и сохраняет найденный номер.

Шаг 3. Как различить день достижения и конец слишком короткого журнала?

Python
day = 0
total = 0
reached_day = None
for duration in minutes:
    day += 1
    total += duration
    if total >= goal:
        reached_day = day
        break
if reached_day is None:
    print("Цель пока не достигнута")
else:
    print("День достижения:", reached_day)
Проверить результат
День достижения: 5

Переменная reached_day изначально хранит None — отметку об отсутствии ответа. Номер попадает в неё только при выполнении условия. Теперь последний день нельзя случайно принять за успешный, а пустой журнал тоже даст осмысленное сообщение.

Программа выполняется. Где ошибка в выводе?

Python
day = 0
total = 0
for duration in minutes:
    day += 1
    total += duration
    if total > goal:
        break
print(day, total)
Разобрать ошибку
6 65

Строгий знак > пропускает ровно 45 минут на пятом дне. На шестом дне условие выполняется, но ответ уже запоздал. Для цели «не менее» сравнение записывают как >=.
